# Erp

## گانت چارت پروژه ERP

- داشبورد تعاملی: [`Gonchar.html`](./Gonchar.html)
- منبع اصلی داده و ساختار گانت: [`erp-project.json`](./erp-project.json)

فایل JSON منبع اصلی ساختار شش‌سطحی گانت است: **۱) حوزه سازمانی، ۲) ماژول، ۳) فرایند، ۴) فعالیت اجرایی، ۵) بسته کاری فنی، ۶) وظیفه قابل واگذاری به توسعه‌دهنده**. داشبورد از همان فایل می‌خواند، درخت و جزئیات را به‌صورت مرحله‌ای باز می‌کند، جست‌وجو و فیلتر دارد، وابستگی‌های بسته‌های فنی و پیش‌نیازهای بین حوزه‌ها را نشان می‌دهد و می‌تواند نتیجه‌ها را به CSV صادر کند. قواعد ارتباط‌ها در `relationship_model` داخل JSON تعریف شده‌اند؛ آن‌ها پیش‌فرض برنامه‌ریزی‌اند و باید هنگام بررسی کد و فرایند واقعی تأیید شوند.

- همه درصدهای پیشرفت در شروع عمداً **۰٪** هستند.
- وضعیت «تکمیل‌شده» فقط پس از بررسی معیارهای پذیرش و ثبت شواهد واقعی مجاز است.
- داشبورد GitHub Pages فعلاً فقط خواندنی است؛ ویرایش از داخل صفحه تا زمانی که مسیر ذخیره‌سازی کنترل‌شده و مجاز پیاده‌سازی نشده باشد، انجام نمی‌شود.
