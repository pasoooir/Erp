# Erp

## گانت چارت پروژه ERP

فایل **[`erp-project.json`](./erp-project.json)** منبع اصلی (Source of Truth) ساختار گانت چارت پروژه است و ساختار چهارسطحی حوزه‌های سازمانی، ماژول‌ها، فرایندها و فعالیت‌های اجرایی را نگه می‌دارد. داشبورد **[`Gonchar.html`](./Gonchar.html)** همین فایل را می‌خواند و وضعیت سطوح چهارگانه، جست‌وجو و فیلترها را نمایش می‌دهد.

- تمام درصدهای پیشرفت سطوح ۱ تا ۴ در شروع عمداً **۰٪** هستند.
- وضعیت‌ها تا ثبت شواهد واقعی «شروع‌نشده» می‌مانند؛ وجود یک فعالیت در گانت به معنی پیاده‌سازی‌شدن آن در محصول نیست.
- پیشرفت فقط پس از بررسی معیارهای پذیرش و ثبت شواهد واقعی باید به‌روزرسانی شود.
