راه‌اندازی مدیر اولیه

این فرم فقط برای ساخت اولین حساب مدیر سامانه است. سرور فقط زمانی آن را می‌پذیرد که راه‌اندازی اولیه هنوز تکمیل نشده باشد.

کلید راه‌اندازی و رمز عبور فقط برای همین درخواست به API امن ارسال می‌شوند؛ این صفحه آن‌ها را ذخیره نمی‌کند. این صفحه را پس از ایجاد مدیر از مخزن حذف کنید.

در حال بررسی وضعیت راه‌اندازی…

اتصال مستقیم HTTPS به Worker پروژه؛ رمز عبور در مرورگر هش نمی‌شود و فقط از طریق TLS به سرور ارسال می‌شود تا سرور آن را با PBKDF2 هش کند.
